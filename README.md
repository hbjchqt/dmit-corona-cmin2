## Corona 在 DMIT 产品线里是什么位置

DMIT 是家美国主机商，AS 号 AS906，机房在洛杉矶、香港、东京，套餐按线路分三档：

- **Pro（Premium）**：三网 CN2 GIA 回程，最贵也最稳，电信用户的优先项。
- **EB（Eyeball）**：三网回程走 CMIN2 和 AS9929，性价比档。
- **T1（Tier 1）**：纯国际线路，不做中国大陆优化，价格最低。

Corona 属于第二个。名字是加州地名，DMIT 用城市名给 EB 系列的档位编号：WEE 最低，往上依次 INTRO、CORONA、FONTANA，配置和价格逐级抬升。

所以 Corona = 洛杉矶机房 + EB 线路 + EB 系列里的中档配置。它经常缺货的原因也在这里：DMIT 把它归为限量特价机，不是常年挂在官网上的正价方案。

## 线路才是这台机器的重点

$49.9 一年买 1 核 1G 本身不算便宜，普通国际线路的商家能给到更低。Corona 被反复讨论，是因为三网回程的走法：

- **移动**：去程和回程都走 CMIN2（AS58807），也就是移动自家的国际精品网。
- **联通**：去程 Telia，回程 AS9929（CUG，联通国际精品线），比常见的 4837 干净。
- **电信**：去程 CN2 GIA，回程在 CMIN2 和 AS9929 之间做混合负载均衡。

拆开看就清楚了：EB 系列对移动和联通用户最友好，电信用户能跑，但拿不到 Pro 线那种纯 CN2 GIA 双向回程的效果。这是产品的定位差别，不是质量问题。

延迟方面，多家公开测试记录里北京、上海、广州三网的 ping 值集中在 150 到 175ms。上海到洛杉矶的物理极限大约 126ms，所以 150 出头已经是压得不错的水平；内陆城市比沿海高 20 到 40ms 属于正常范围，不是机器有问题。

有一点必须提前说清楚：DMIT 对 EB 系列的官方口径并没有承诺"保证三网优化"，实际使用中绝大多数时段确实走在优化线上，但和 Pro 线的签约保障不是一回事。这也是它便宜的原因之一。

## 下单前得先知道这几条规则

限量特价机和正价机的购买体验不太一样，规则也更细：

**库存**：按批发售，有补货记录显示每日限量约 100 单，未付款的订单 3 小时自动取消。看到有货犹豫两天，大概率就没了。

**退款**：3 天内且流量使用不超过 30GB，可全额退款；1 个月内按剩余价值退款，会扣掉支付网关手续费。这条比很多同价位商家宽松，但别把"能退"当成"先买来试"的常规操作。

**换 IP**：IP 被墙的前提下，每 15 天可以免费更换一次，超出频率 $5 一次。买之前先用官方测试 IP `154.17.226.2` 自己 ping 一轮，比看任何测评都直接。

**优惠码**：限量特价机基本不参与常规优惠码，也没必要等。DMIT 在部分正价线（比如香港、东京的 Pro 和 T1）上做过季付及以上周期 8 折、7 折的官方折扣活动，这类折扣以结算页最终价格为准，不建议按老活动预期下单。

## 谁适合买，谁别买

适合的情况：

- 家宽是移动或联通，主要用途是代理节点、转发、自动化脚本
- 个人博客或静态站点，访问量不大
- 需要一台晚高峰别抖的美西机器，预算卡在 $50 一年
- 能接受"看到有货就下手"的抢购节奏

不太适合的情况：

- 要跑 MySQL、多个 Docker 容器之类吃内存的服务，1GB 会很快到顶
- 电信宽带且对延迟极其敏感，Pro 线更对路
- 需要大量 CPU 的计算任务，单核是硬上限
- 今天下单今天就想要，不接受等补货

## 几个常见问题

**Corona 的补货有规律吗？**
没有固定时间表。DMIT 一贯的做法是"有货就上，卖完就等"，有时候隔几周补一批，有时候补上几天就售罄。宣传渠道和补货公告是主要信息来源。

**1GB 内存实际能装什么？**
精简安装 Debian 或 Ubuntu 之后可用内存大约 600 到 700MB。Nginx 加静态站、轻量代理、监控和定时任务都没问题，带数据库的应用要谨慎评估。

**能解流媒体、能用 ChatGPT 吗？**
按 2025 年 12 月的第三方 IP 检测记录，Netflix 美区、YouTube Premium、Amazon Prime 可用，Hulu 和 Disney+ 判定不可用，ChatGPT、Gemini、Claude 判定可用。IP 段会变动，把这组数据当参考而不是永久承诺。

**可以月付吗？**
限量特价机一般是年付制，季付及以上周期会有更多选项。想月付就得看正价线。

**Corona 比 WEE 贵的那 $10 花在哪儿？**
CPU 和内存完全一样，差在流量和端口：WEE 是 1000GB / 1Gbps，Corona 是 2000GB / 2Gbps。换算下来就是一年多花 $10 换每月多 1TB 流量和翻倍端口，用量大的话这笔差价不亏。

**和 FONTANA 比呢？**
FONTANA 是 2 核 2G 40G，4000GB 流量配 4Gbps 端口，$100 一年。Corona 的配置够个人用，FONTANA 的余量适合放小站或者几个人共用。预算能翻倍就直接上 FONTANA，不用纠结。

绕回最初那个问题：Corona 值不值。它的价值不在硬件本身，1 核 1G 20G 是标准配置，谁家都能给；值钱的是 CMIN2 加 AS9929 的三网回程，以及 $49.9 这个价位上给到的 2000GB 流量和 2Gbps 端口。移动和联通用户拿到的是这个价位里少见的线路组合，电信用户则要接受它不如 Pro 线极致这个事实。至于抢不抢得到，那是另一个问题了。
